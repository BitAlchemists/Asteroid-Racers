Race mode (singleplayer)

  • Singleplayer — the server runs in your browser
  • Multiplayer — everyone on this server races together, with the server's bots (the server picks the track)
  • Model showcase — watch a trained model fly every track, training arena and the race exam, with results
  • Watch the AI — a trained model flies the race exam, or the chosen track

Controls

← → turn, ↑ thrust (or A D W), 1 toggles the interface. Fly into the green start pad to join the race; click it (or “Leave race”) to leave.

On a phone: drag anywhere on the left half to steer (the ship turns to point where you drag), hold anywhere on the right half to thrust.
